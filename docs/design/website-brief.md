### CH04 · 現象觀察

**標題**：有三個現象印象最深

**現象一：工具一直換**
- 今天 Claude Code / 明天 Cursor / 後天又是另一套
- 關鍵訊息：**追工具不是核心——工具會換，工作方式可以沉澱**

**現象二：瓶頸在工作方式**
- 需求沒整理好 / 文件沒有結構 / PM SA SD 說法不同 / AI 不知道聽誰的
- 關鍵訊息：**工作方式沒整理好，AI 只會放大混亂**

**現象三：能力差距被放大**
- 強的用 AI 後更強 / 本來混亂的更混亂
- 核心能力：問題拆解 / 架構判斷 / 驗證
- 關鍵訊息：**AI 需要被放進可控的工作環境**

### 配色系統
| Token | 色碼 | 用途 |
|---|---|---|
| 主背景 | `#F8F9FA` | 頁面底色 |
| 卡片白 | `#FFFFFF` | 卡片、內容區塊 |
| 次背景 | `#F0F4F8` | 分隔區塊 |
| 主文字 | `#1C1C1E` | 標題、正文 |
| 次文字 | `#3C3C43` | 副標、描述 |
| 灰文字 | `#6E6E73` | 說明文字 |
| 主強調色 | `#4A90E2` | 按鈕、標籤、重點框線（Slate Blue） |
| 深強調色 | `#003366` | 大標題強調、Executive Navy |
| 成功綠 | `#34C759` | 正向數據 |
| 警示橙 | `#FF9500` | 次要強調 |
| 分隔線 | `#E5E5EA` | 線條、邊框 |

### 設計原則
- **風格**：白底深藍，企業 SaaS 風格，專業清爽
- **圓角**：卡片 10px，按鈕 6-8px
- **陰影**：輕量（`0 2px 8px rgba(0,0,0,0.06), 0 8px 24px rgba(0,0,0,0.08)`）
- **底紋**：可加 48px 方格網格底紋（`rgba(0,0,0,0.05)`），增加層次感
- **字型**：繁體中文建議 Noto Sans TC / PingFang TC；數字使用等寬字體
- **字級**：大標題 48-64px / 章節標題 32-40px / 正文 16-18px

### 不要的風格
- ❌ 漸層背景（保持純色）
- ❌ 大圓角（>12px 顯得過於消費化）
- ❌ 螢光 / 發光效果（留給暗色版）
- ❌ 動態過多（商務場合保持穩重）
